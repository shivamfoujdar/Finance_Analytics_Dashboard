Finance Analytics Dashboard | Power BI
📊 Project Overview

The Finance Analytics Dashboard is an interactive Power BI project designed to analyze financial transactions, customer behavior, transaction performance, fees, taxes, and Year-over-Year (YoY) growth. It provides actionable insights through dynamic visualizations, KPI tracking, and detailed transaction analysis to support data-driven business decisions.

🎯 Business Objectives
Monitor overall financial performance and transaction growth.
Analyze monthly transaction trends and YoY changes.
Evaluate successful, failed, and pending transactions.
Identify high-performing customer segments and states.
Track transaction fees, taxes, and transaction types.
Understand customer demographics by gender.
Enable detailed transaction-level analysis through drill-down.
📌 Key Performance Indicators (KPIs)
Total Amount: Total transaction value with YoY growth comparison.
Total Transactions: Total number of transactions and yearly volume changes.
Average Transaction Value: Average amount per transaction.
Total Fees: Total fees collected from transactions.
Total Tax: Total tax generated from transactions.
📈 Dashboard Features & Visualizations
Dashboard 1: Finance Performance Overview
Total Amount by Month: Line or area chart to analyze monthly trends.
Transaction Status Analysis: Donut chart comparing Success, Failed, and Pending transactions by amount.
Customer Segment Analysis: Horizontal bar chart comparing Retail, Premium, SME, Corporate, and Wealth segments.
State-wise Performance: Horizontal bar chart identifying top-performing states.
Transaction Type Analysis: Matrix or heatmap displaying Amount, Fees, Tax, and Transaction Count.
Gender Analysis: Donut chart comparing transaction amount contributions by Male and Female customers.
Dashboard 2: Detailed Transaction Analysis
Detailed transaction grid for underlying records.
Drill-down capabilities for deeper transaction analysis.
Supports investigation of transaction-level performance and patterns.
